## About The Project

**WellnessOS** is a responsive wellness analytics dashboard designed to transform a full year of wearable watch telemetry into an actionable morning synthesis report for January 1, 2026. 

Anchored to a fixed 7-day evaluation window (Dec 25 – Dec 31, 2025) for consistent benchmarking, the dashboard bridges static reporting and live data tracking by featuring:
- **Clinical Vitals & Weekly Marks**: Daily step count, active minutes, caloric burn, sleep architecture, and hydration tracking.
- **National Baseline Comparisons**: Real-world benchmarks for objective habit assessment.
- **Personalized Movement Protocols**: Daily exercise and mobility recommendations paired with guided movement visuals.
- **Gamified Habit Matrix**: Consistency trackers with streak multipliers to build sustainable daily routines.
- **Simulated Real-Time Sync**: Watch telemetry sync engine to bridge the gap between static summaries and live data updates.
